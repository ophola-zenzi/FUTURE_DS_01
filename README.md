# Business Sales Performance Analytics

This repository contains a beginner-friendly business sales analytics project for a Data Science internship. It uses Python to generate a realistic sales dataset, clean and summarize it, and produce a client-ready report and dashboard.

## What is included
- A synthetic sales dataset in CSV format
- A Python analysis workflow for revenue, profit, product, and region analysis
- A professional Markdown report with insights and recommendations
- A simple HTML dashboard for presentation use

## Files
- [sales_analysis.py](sales_analysis.py): Main analysis workflow
- [#Future Interns DS Internship.py](#Future%20Interns%20DS%20Internship.py): Entry script to run the project
- [sales_analysis_report.md](sales_analysis_report.md): Executive report
- [sales_dashboard.html](sales_dashboard.html): Dashboard view
- [requirements.txt](requirements.txt): Python dependencies

## How to run
1. Install dependencies:
   pip install -r requirements.txt
2. Run the project:
   python "#Future Interns DS Internship.py"

## Deliverables
The project highlights:
- Revenue trends over time
- Top-selling products
- Profitable regions
- Strongest product categories

These outputs are ready to be shared as part of an internship portfolio or business case presentation.
